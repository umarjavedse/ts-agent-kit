# Security policy

## Supported versions

Security fixes are made for the latest released version of ts-agent-kit.

## Reporting a vulnerability

Please report vulnerabilities privately rather than in a public issue:

- Use GitHub's **Report a vulnerability** button on the repository's **Security** tab, or
- Email **umarjavedse@gmail.com** with the subject `[ts-agent-kit] security`.

Include a description of the issue, steps or code to reproduce it, and the impact you expect. You should receive a reply within a few days. Once a fix is released, you will be credited in the release notes unless you prefer otherwise.
